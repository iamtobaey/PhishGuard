# PhishGuard
PhishGuard: An end-to-end ML system detecting phishing via 30 URL &amp; webpage features. Includes a full data science pipeline, 8-model comparison (Champion: MLP, 94.65% Acc), SHAP explainability, and a FastAPI backend. Built to MSc standards with focus on robustness, XAI, and real-time inference. Tech: Python, Sklearn, XGBoost, FastAPI, SHAP.
